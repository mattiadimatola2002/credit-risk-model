# Credit Risk Modelling

Three probability-of-default models built in R:
- Financial statement model (trade-sector firms)
- Credit behaviour model (micro-enterprises)
- Integrated model (micro-enterprises in trade)

Out-of-sample AUROC: 0.719 / 0.819 / 0.826
